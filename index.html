Setting up in Roll20

Everything here fits one grid: a Hex (V) page with 70 px cells. Images are drawn at 2× for sharp zooming; the size to set in Roll20 is in every file name (crate_v1_70x81.png → 70 × 81 px).

A base map holds only what never changes: the floor, the zones and the decals. Terrain that can be destroyed (walls, cover, raised ground) goes on as tokens, so you can delete it when it's shot away.

Nothing leaves your browser

Maps and tokens are drawn on your computer. The Map Maker keeps your current map in this browser between visits; save it as a .json file to keep it for good.
